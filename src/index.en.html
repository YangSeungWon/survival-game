Survival Game — Vampire Survivors-style Roguelike

Survival Game is a free vampire-survivors-style roguelike you can play directly in your browser. Dodge endless waves of enemies, auto-attack to clear the screen, collect experience to level up, and pick power-ups to build an unstoppable character. No install required — playable on both desktop and mobile.

How to play

  • Move: arrow keys or the on-screen joystick
  • Attack: automatic (auto-aims the nearest enemy)
  • Upgrade: choose a power-up each time you level up

Features

  • Varied enemies & bosses — ranged wizards, fast rushers, elites, a final boss
  • Multiple attack types — projectile, beam, area-of-effect, melee
  • Roguelike power-up builds — a different run every time
  • Mobile support — touch joystick for phones / iPad
